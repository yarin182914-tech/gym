# Feature specs

One file per feature, written by `/feature` (`.claude/commands/feature.md`) before any code: why, what it does, screens and states, flow, rules and numbers, Firestore data, what's out, and the done-criteria. Product parts in Hebrew, technical parts in English.

Status line at the top of each spec: `draft` (being discussed) → `approved` (ירין said yes) → `built` (matches the merged code).
